# External method template

This separately installable fixture scales an example backend's actions to test
discovery, compatibility and detach semantics. It is not an acceleration algorithm.
Copy its package structure, not its mechanism; implement the declared paper method
or independent core contribution and replace the metadata, config and factory.
Disclose omitted components and adaptations. See docs/development.md (Add a method).

```bash
python -m pip install -e templates/method
evb list
```
